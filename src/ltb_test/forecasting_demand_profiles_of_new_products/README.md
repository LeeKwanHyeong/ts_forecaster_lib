# Forecasting demand profiles of new products

[van Steenbergen & Mes (2020), *Decision Support Systems* 139, 113401](https://doi.org/10.1016/j.dss.2020.113401)

논문의 **수요 곡선 형태와 총량을 따로 예측한 뒤 결합하는 접근**을 서비스 부품에 적용한 작업이다. 출시 후 18주 분석은 논문의 DemandForest(K-means, Random Forest, Quantile Regression Forest)를 참고한 구현이다. LTB 12→60개월·24→60개월 작업은 같은 아이디어를 장기 부품 수요에 적용한 별도 실험이다. 논문 전체를 그대로 재현한 것은 아니다.

## 주요 결과와 한계

- **출시 18주:** 개발 데이터의 검증 품목 92,000개에서 주별 WAPE는 학습 평균 **120.2%**, QRF와 공통 곡선 **91.9%**, RF와 QRF 결합 **83.8%**였다. 결합 방식의 90% 주별 예측구간 적중률은 **38.2%**였다. 판매 시작일은 출시 시점을 정렬하는 기준일이며, 판매량은 모델 입력이 아니다. 현재 마스터 속성이 출시 당시에도 같았는지는 검증하지 않았다.
- **V100 12→60개월:** 2024년 1~3월 적용분 460개에서 개발 관측 총량은 **368,881 EA**, 균등 배분 예측은 **386,500 EA**, 총량 보정 모델은 **1,051,731 EA**였다. 부품별 60개월 합계를 비교한 누적 WAPE는 **27.29% → 188.79%**로 악화됐다. 개발 데이터의 정책 적용월은 실제 LTB 승인일이 아니다. 별도 원인 진단에서는 두 집단에 같은 적용월 산식을 썼지만, 합성 판매 생성이 끝나는 시점이 2024년 평가 집단과 겹쳤다.
- **부품 수요 합성 실험:** 같은 평가 부품 1,350개와 같은 부품별 예측 총량에서 하락·유지·상승 비율을 `10:20:70`에서 `1:1:1`로 바꾸자, 하락형 450개에 상승 곡선을 배정한 건수가 K=3은 **428 → 95**, 첫해 비중 직접 예측은 **360 → 78**로 줄었다. 전체 월별 WAPE는 **균등 배분 55.86%**, **균형 K=3 58.76%**, **균형 첫해 비중 직접 예측 56.59%**였다. 판매량·판매 계획·패턴 라벨은 예측 입력이 아니다. 합성 실험의 1:1:1을 실제 운영의 최적 비율로 보지 않는다.
- **운영용:** 실제 운영 데이터 검증과 적용 승인은 별도다. 예측값은 수요 추정치로, 발주량이 아니다.

V100의 **누적 WAPE**는 부품별 60개월 합계의 오차를, 합성 실험의 **월별 WAPE**는 부품·월 단위 오차를 집계한다. 데이터와 집계 기준이 달라 두 점수를 직접 비교하지 않는다.

## 로컬에서 다시 실행하기

Jupyter에서 `Python (ts_forecaster)` 커널을 선택한다. 아래의 로컬 입력만 사용하며 DB에 새로 접속하지 않는다. 누락된 주·월은 관측된 0수요와 구분한다. LTB 학습에서는 평가·결정월 전에 60개월 관측이 끝난 부품만 쓰고, 평가 부품의 이후 수요는 예측 입력에 넣지 않는다.

- **출시 18주:** 저장소 루트의 `raw_data/ltb_new_product_profiles/`에 있는 `tb_mst_oper_part.parquet`, `demand_detail_2018W01_2025W44/`와 각 Manifest를 사용한다. 루트를 찾지 못하면 `TS_FORECASTER_ROOT`에 저장소의 절대 경로를 지정한다. 기본 실행은 결과를 저장하지 않는다.
- **V100 백테스트:** `LTB_DEV12_ROOT`에 `monthly_scope_V100_live_development.csv`와 `extract_manifest_live_development.json`이 있는 폴더의 절대 경로를 지정한다. 기본 경로는 `/private/tmp/ltb_dev12_experiment_20261124`다. 임시 파일이 없어졌다면 같은 개발 추출본이 필요하다. 실행 시 그 폴더에 집계 결과를 쓰므로, 기존 결과를 보존하려면 두 입력을 복사한 별도 작업 폴더를 지정한다.
- **부품 수요 합성 실험:** 외부 데이터 없이 Notebook 안에서 같은 시드로 재생성한다. 결과 경로는 `LTB_PART_DEMAND_OUT`으로 바꿀 수 있다.
- **운영용:** `LTB_OP_DECISION_MONTH`(월 첫날, `YYYY-MM-01`), `LTB_OP_TRAIN_PATH`, `LTB_OP_SCORING_PATH`를 지정한다. 입력은 서로 다른 로컬 Parquet의 절대 경로다. 학습에는 `part_key`, `decision_month`, `completed_month`, `month`, `demand_qty`가, 예측에는 `part_key`, `month`, `demand_qty`가 필요하다. 저장하려면 아직 존재하지 않는 파일을 `LTB_OP_OUTPUT_PATH`로 지정한다. 생략하면 결과는 Notebook 실행 중에만 조회할 수 있다.

# [보고서] 수요 예측 모델(PatchTST) 미래 변수 반영 방식 개선 결과

## 1. 요약 (Executive Summary)
수요 예측 모델이 프로모션, 보증 기간 종료 등 '미래에 예정된 정보(미래 변수)'를 반영할 때 발생하던 **예측 불안정성(특정 시점의 예측값이 비정상적으로 튀거나 0이 되는 현상)**을 해결했습니다.

기존의 '단순 병합 방식'을 폐기하고, 과거의 패턴과 미래의 변수를 시점별로 자연스럽게 연결하는 **'시점별 상호작용(Cross-Attention) 방식'**을 새롭게 도입하여 예측 안정성을 대폭 끌어올렸습니다.

## 2. 배경 및 문제점
정확한 수요 예측을 위해서는 과거의 판매량뿐만 아니라, 예측 시점에 이미 계획되어 있는 **미래 조건(보증 종료 시점, 예정된 캠페인 등)**을 모델이 활용할 수 있어야 합니다.

하지만 기존 모델이 이 미래 정보를 받아들이는 방식에 치명적인 구조적 결함이 발견되었습니다.

* **시간의 흐름 무시:** 1주차, 2주차, 3주차의 미래 정보를 시간 순서대로 보지 않고, 하나의 거대한 데이터 덩어리로 뭉뚱그려(Flatten) 모델의 마지막 단계에 한 번에 쏟아부었습니다.
* **개별 품목의 특성 상실:** 미래 정보가 너무 강하게 주입되다 보니, 모델이 품목별(Part) 고유한 과거 판매 패턴을 무시하고, 모든 품목을 비슷하게 예측해버리는 현상이 발생했습니다.
* **결과적인 예측 실패:** 이로 인해 특정 주차의 예측값이 비정상적으로 치솟거나(Spike), 뚝 떨어지는 불안정한 결과가 나타났습니다.

## 3. 개선 방안: '시점별 상호작용' 방식 도입
기존의 뭉뚱그리는 방식을 버리고, 미래 정보를 시간의 흐름(예측 주차)에 맞게 유지하면서 과거 데이터와 결합하는 새로운 방식을 도입했습니다.

* **시간 구조 보존:** 미래 정보를 거대한 덩어리로 만들지 않고, 1주차, 2주차 등 각 시점별 단위로 유지합니다.
* **자연스러운 상호작용(Attention):** 모델이 과거의 판매 패턴을 분석할 때, 그에 맞는 미래 시점의 정보만 선택적으로 참고하도록 연결고리를 만들었습니다.
* **효과:** 품목별 고유한 특성을 유지하면서도, 미래의 이벤트가 해당 시점의 예측에만 정확히 영향을 미치도록 개선되었습니다.

| 구분 | 기존 방식 (단순 병합) | **신규 방식 (시점별 상호작용)** |
| :--- | :--- | :--- |
| **미래 정보 처리** | 시간 흐름을 무시하고 하나로 뭉침 | **시간 흐름(주차별) 구조 유지** |
| **과거 데이터와 결합** | 모델 마지막에 억지로 끼워 넣음 | **과거 패턴 분석 시 자연스럽게 참고** |
| **예측 안정성** | 매우 낮음 (값이 자주 튐) | **매우 높음** |
| **결론** | **사용 불가 (폐기)** | **새로운 표준으로 채택** |

## 4. 검증 결과 (A/B 테스트)

두 가지 방식을 동일한 조건에서 테스트한 결과, 신규 방식의 우수성이 명확히 입증되었습니다.

**① 기본 데이터셋(Walmart) 검증: 구조적 결함 해결**
* 기존 방식은 오차율(WAPE)이 **1.28** 수준으로 사실상 예측이 망가지는 수준이었습니다.
* 신규 방식을 적용하자 오차율이 **0.58**로 절반 이상 줄어들며, 예측이 정상적이고 안정적인 궤도에 올랐습니다.

**② 실제 비즈니스 데이터(DSIO) 검증 및 시사점**
* 실제 당사 데이터 적용 시, 신규 방식이 기존 방식의 기술적 오류를 해결하여 안정적으로 작동함을 확인했습니다.
* 다만, 당사 데이터에서는 두 모델 모두 실제 정답(GT)보다 수요를 높게 예측하는 공통된 경향이 나타났습니다.
* 이는 **모델의 기술적 구조 문제는 해결되었으며, 이제는 '입력되는 데이터의 품질과 학습 방식'을 개선해야 할 단계**임을 시사합니다.

## 5. 결론 및 향후 계획
1.  **신규 방식 표준화:** 향후 수요 예측 모델에 미래 변수를 추가할 때는, 기술적 결함이 있는 기존 방식을 폐기하고 **'시점별 상호작용(Cross-Attention)' 방식을 표준으로 사용**합니다.
2.  **데이터 및 학습 고도화 (Next Step):** 모델의 구조적 안정성이 확보되었으므로, 향후에는 DSIO 데이터의 특성을 반영한 개선에 집중합니다.
    * 단종되거나 수요가 매우 적은 불규칙한 품목(Erratic/Obsolete segment)에 대한 별도 대응
    * 품목의 생애주기(Lifecycle) 반영 강화 및 예측값 미세 조정(Calibration)

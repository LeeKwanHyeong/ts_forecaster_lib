# MORA 보정 강도와 일반화 진단

작성일: 2026-11-20
대상: `ts_forecaster_lib` / `ts_forecaster_lib_v2`
기준 실험: [동결 Chronos2 실제 비교](Chronos2MORARealComparison20261120.md)

## 결론

검증 calibration이 실제 보정량을 크게 줄인 상태. 다만 강도를 제거하면 검증·시험 오차가 크게 늘어나므로, 유효한 보정을 과도하게 억제한 문제로만 해석할 수 없는 결과.
학습에서 유효했던 추가 구간평균 추정기의 검증·시험 일반화 실패와 부품·기간 사이 수요 분포 차이가 주요 진단 근거.
기존 코드·가중치·보정 체크포인트·실험 산출물은 변경하지 않은 사후 분석.

## 실제 보정량

시험 1,050부품 × 27주, 총 28,350개 점예측 기준. 수량 단위는 원본 수요 단위.

| 항목 | 값 |
|---|---:|
| calibration 전 평균 절대 보정량 | 6.474284 |
| calibration 후 평균 절대 보정량 | 0.093393 |
| 평균 절대 보정량 감소율 | 98.5575% |
| 최종 절대 보정량 중앙값 | 0.042859 |
| 최종 절대 보정량 95백분위수 | 0.356209 |
| 최종 절대 보정량 최대값 | 1.664132 |

최종 보정 절댓값 합 / 원본 예측 절댓값 합은 0.4398%. 점별 상대 변화율의 평균과는 다른 지표.
27,300개 점예측은 실제 변경됐으며 첫 예측 주차 1,050개는 기저 설계에 따라 원본 유지.
전체 평균에는 변경되지 않은 첫 주차도 포함.

## 보정이 작아진 단계

`adapter.py:predict`는 1·2단계 계수를 합산한 후 `state.calibration`을 곱해 기저 공간에서 수요 단위로 복원하는 구조.

| 기저 계수 그룹 | calibration | 시험의 보정 전 제곱합 비중 |
|---|---:|---:|
| 1–4 | 0.000542 | 99.8724% |
| 5–8 | 0.546565 | 0.0493% |
| 9–12 | 1.168954 | 0.0057% |
| 13–16 | 0.067584 | 0.0727% |

기저 계수 그룹이며 예측 주차 그룹이 아닌 구분. 가장 큰 성분에 해당하는 첫 그룹이 거의 제거되면서 작은 성분만 유지된 결과.
첫 기저의 학습 gain은 1단계 0.752695, 2단계 0.886126으로, 모든 gain이 0이거나 연결이 누락된 상태와는 다른 동작.

### 강도를 모두 1로 둔 사후 진단

기존 학습 매핑·gain은 유지하고 calibration만 모두 1로 두어 산술 재계산한 결과. 재학습·모델 선택·새 체크포인트 저장은 미수행.

| 조건 | 검증 MAE | 시험 MAE |
|---|---:|---:|
| Chronos2 원본 | 7.250111 | 2.215364 |
| calibration 모두 1 | 9.424050 | 6.950005 |
| 기존 calibration | 7.246992 | 2.216366 |

검증에서 실제로 손해였던 큰 보정을 줄이는 안전 장치로 작동한 정황.
이미 사용한 시험 결과의 진단이며 새 미사용 시험의 성능 증거와는 구분.

## 추가 구간평균 추정기의 일반화

H27을 6개 구간으로 나눈 평균값의 오차이며, 위의 주차별 점예측 MAE와 서로 다른 지표.

| 구분 | Chronos2 구간평균 MAE | MORA Ridge 구간평균 MAE |
|---|---:|---:|
| 학습 내부 교차검증 | 7.223425 | 6.603900 |
| 검증 | 7.433589 | 11.619234 |
| 시험 | 2.268063 | 11.562046 |

저장된 1·2단계 gain은 같은 학습 창의 OOF·nested OOF 재계산과 일치.
학습 내부에서는 유효했던 추가 평균 추정이 검증·시험에서는 원본 Chronos2보다 부정확한 결과.
공용 부품 보정(`pooled_series`)과 고정 compact 특징을 사용한 이번 구현에 한정된 관찰이며, 논문 전체 방법의 일반적인 실패로 해석 불가.

### 수요 분포 차이

- 전체 허용 학습 창 1,080,909개 중 정답 27주 전체 0수요인 창 0개. 선택한 19,600개만의 표집 누락은 아닌 결과
- 검증 1,050개 창 중 전체 0수요 창 1개
- 시험 1,050개 창 중 전체 0수요 창 657개, 62.57%
- 선택한 창의 주당 평균 실제 수요: 학습 95.5510, 검증 30.0632, 시험 19.2501

부품 ID와 정답 기간이 함께 분리되어 있어 시간 변화와 부품군 차이의 영향을 이 실험만으로 구분하지 못하는 조건.
전체 0수요는 관측 수요에 대한 분류이며 단종·생애주기 종료 판정은 아닌 구분.

## Calibration 최적화 점검

현재 설정은 bounded IRLS 최대 8회. 같은 검증 자료·보정 성분·목적함수에 독립 L-BFGS-B를 적용해 수치 최적화 상태만 점검.

| 항목 | 목적함수 |
|---|---:|
| 무보정 | 1.000018014 |
| 모든 강도 1 | 1.299476109 |
| 저장된 강도 | 0.999498497 |
| 독립 검증용 최적화 | 0.999425406 |

더 낮은 검증 목적함수의 해가 존재하나 차이는 0.000073092. 독립 해의 첫 그룹 강도는 0으로, 주요 성분의 억제를 완화하는 방향이 아닌 결과.
독립 해 `[0.0, 0.519620, 1.5, 0.114951]`는 시험에 적용하거나 보정기로 저장하지 않은 상태.
반복 수·수렴 검사를 개선할 여지는 있으나 보정량이 작아진 주원인이라는 근거는 부족.

학습 gain은 제곱오차 기반 비율로 정하고 calibration은 정규화 MSE·평활 MAE의 혼합 목적함수를 사용하므로, 어느 단계도 모든 부품의 MAE 개선을 보장하지 않는 구조.

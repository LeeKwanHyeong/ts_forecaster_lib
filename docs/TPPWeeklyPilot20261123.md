# TPP 주간 수요 검증

- 대상: `ts_forecaster_lib_v2`의 후보 wheel `modeling_module-0.2.1rc1`.
- 결과: 실제 수요 학습 및 5090 런타임 검증 완료. 운영 모델 채택 보류.
- 산출물: `dist/tpp-validation/weekly-pilot-20261123/`의 검증용 가중치 3개와 집계 결과 JSON.

## 검증 조건

- 원천: `raw_data/master/tb_master_target.parquet`, 2,455,508행, 7,000부품, 201801~202544. 사용자가 실제 관측으로 확인한 0수요 사용. 누락 주차를 0으로 보정하지 않음.
- 간헐·불규칙 수요 후보 560부품: 검증 시작 전 관측값으로만 ADI 1.32 이상 및 양수 수요 10회 이상 판정. 양수 수량의 CV² 0.49 이상 18부품 별도 층화.
- 후보 391/84/85부품을 학습/검증/시험으로 서로 겹치지 않게 분리. L104/H26, 입력 최대 32이벤트·최소 4이벤트. 학습 창 3,007건, W0 202419의 검증 가능 부품 64개.
- 시험 W0 202445·202506·202519, 부품-시작주차 조합 240건. 세 예측 기간은 일부 중첩. H26 경로 16개 평균. 학습 4 epoch 중 별도 검증군의 H26 WAPE로 체크포인트 선택.
- TSB 비교는 동일 관측 이력의 `alpha=beta=0.1` 고정 기준선. 모델 종류와 시점별 재최적화 없음.

## 시험 결과

H26 WAPE는 각 부품·시작주차의 26주 합계 오차 절댓값을 모두 더한 뒤, 해당 실제 합계 수요의 총합으로 나눈 값. 편향은 전체 예측 합계와 실제 합계 차이를 실제 합계로 나눈 값.

| 모델 | 주간 WAPE | H26 WAPE | 합계 편향 | 채택 epoch |
| --- | ---: | ---: | ---: | ---: |
| Mean52 | 275.5% | 186.5% | +184.1% | - |
| TSB | 275.0% | 186.0% | +184.0% | - |
| RMTPP matched head | 286.6% | 277.7% | +267.5% | 1 |
| PHEN | 207.4% | 97.0% | +93.4% | 4 |
| S2P2 matched head | 82.6% | 79.1% | +68.4% | 4 |

세 시험 시작점에서 실제 26주 수요는 직전 26주 대비 각각 51.0%, 37.2%, 45.6%. S2P2는 비교군 중 오차가 가장 낮지만 총량 과대예측이 남음. 불규칙 수요 분류군 시험 표본은 3부품(9개 조합)뿐이며 실제 수요 합계의 비중도 낮아, 이 유형의 모델 채택 근거로 사용하지 않음. 현재 결과는 단일 데이터 스냅샷과 시드의 파일럿 결과.

## RTX 5090 확인

- Python 3.12.13, PyTorch 2.11.0+cu130, CUDA 13.0. 공용 `ai_env`는 읽기 전용으로 사용하고 후보 wheel은 5090의 임시 경로에만 설치.
- 세 실제 학습 가중치를 복원한 뒤, 원천 수요가 아닌 합성 이력 2개와 고정 시드로 CPU/CUDA H26 이벤트 경로 비교. 경로별 이벤트 위치 동일, 생성 수량은 `rtol=5e-4`, `atol=1e-5` 이내. JSON 변환 성공.
- 원천 수요, 자재 식별자, 시험 데이터 원본 미전송. `DemandEngine`, 공용 배포, 모델 운영 플래그 미변경.

재현 도구: `tools/validate_tpp_weekly_pilot.py`. `--parquet`과 새 `--output` 경로를 주면 실제 수요 파일럿 실행. 검증용 가중치 디렉터리에 대해 `--cuda-check --output`으로 비교 실행.
